# iOS application

Open `ZOVARA.xcodeproj` with macOS/Xcode. The project references the SwiftUI/WebKit source and `Info.plist`. Set `ZOVARAWebURL` in `Info.plist` to the deployed HTTPS origin, select an Apple development team, and configure signing/capabilities before running on a device or archiving. Test camera/microphone prompts and LiveKit connectivity on physical devices. This runner does not include macOS/Xcode or signing credentials, so no archive or IPA is claimed.
