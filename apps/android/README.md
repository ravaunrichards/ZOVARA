# ZOVARA Android

Native Kotlin + Jetpack Compose application shell, configured for Android SDK 36 and min SDK 26. The shell builds independently and provides the native navigation / brand base. Before release, complete signed-in API session, feed paging, upload lifecycle, push registration, deep links, and LiveKit room lifecycle against the shared API; do not present the shell as store-ready until these device flows and instrumentation tests pass.

Build with Android Studio or `gradle :app:assembleDebug` from this directory using an installed compatible Android SDK.
