# ZOVARA administration console

Administrative actions require server-enforced role checks, least privilege, audit events and reason capture. The client must not infer administrator status from editable profile metadata.

Core modules: user/account review, content reports, moderation queues, appeals, payment investigation, creator payout review, platform configuration and audit logs. Sensitive actions require confirmation and show resulting server state. Support staff must not edit ledger history or manually mark provider payouts as settled.
