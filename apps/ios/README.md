# ZOVARA iOS

A SwiftUI starter target and Xcode project are included under `ZOVARA.xcodeproj`. The target establishes native tab navigation and the product's visual foundation; it is not yet a production-complete native client. Before release, implement and test API session persistence, feed pagination, AVFoundation upload, deep links, push-notification entitlements, LiveKit room lifecycle, accessibility, and App Store privacy declarations on actual devices and supported SDKs.

Open `ZOVARA.xcodeproj` in a compatible Xcode version. This repository was authored in a Linux environment; Xcode/macOS builds and signing were not run here.
