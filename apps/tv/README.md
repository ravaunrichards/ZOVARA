# TV experience

The responsive shared web client has a TV presentation mode with enlarged targets, strong focus rings, and keyboard/remote arrow navigation. Open the deployed origin with `?tv=1` on a compatible Android TV/WebOS/Tizen browser or supported web runtime. Current source is platform-neutral; store-ready platform-specific Tizen/WebOS packages are not included or falsely claimed. Use a focused remote-navigation QA session on each actual TV target before publication.
