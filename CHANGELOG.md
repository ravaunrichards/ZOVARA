# Changelog

## 0.1.0 — Initial build
- Created a single monorepo with responsive web/PWA, Android WebView shell, iOS SwiftUI shell, desktop wrapper source, and TV-oriented interface.
- Added Node.js API routes with Supabase, PayPal, and LiveKit adapters that fail explicitly when credentials are absent.
- Added PostgreSQL migrations, RLS policies, gift accounting functions, gifter badge catalog, 100-gift catalog, 1,000 style combinations, generated asset manifests, tests, and CI.
- This release is a functional foundation, not a claim that every listed ecosystem feature is already complete or that third-party services are deployed.
