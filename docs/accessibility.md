# Accessibility and inclusive design

The web app includes focus rings, semantic main/navigation regions, skip link, form labels, status announcements, responsive focus targets, contrast variants and reduced-motion controls. Media controls are shown only after user intent. Verify using keyboard-only navigation, screen readers, a WCAG contrast checker, 200% zoom, large text, Android TalkBack, iOS VoiceOver and the actual TV remote. Automated accessibility scans were not executed unless shown in verification reports.
