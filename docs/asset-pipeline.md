# Asset registry and provenance

Catalog and icon files are generated by `scripts/generate-catalog-seeds.mjs` plus the source templates in the build script included in this repository history? The checked-in JSON and vector files are the release inputs of record. `assets/manifest.json` includes path, SHA-256, category and asset counts; catalog manifests identify each item's individual path and checksum. Generated SVGs are original programmatic vector prototypes for this release, not commissioned meshes or rendered 3D files. `null` sound references mean no sound is produced; they are not treated as missing functional audio. All SVG files are local/no external network references. Review the manifest before adding assets and keep attribution/licensing data current.
